# CompeteMath

The knowledge, security and reliability layer for agentic formal theorem provers.

- **[Tengoku](https://github.com/competemath/tengoku)**: an open-source Lean 4 formal knowledge tree. Many libraries on one toolchain, open to contributions.
- **[Leak](https://competemath.com/leak)**: the verification behind it.
- **[competemath.com](https://competemath.com)**: a competitive mathematics arena. New problems every day, formally verified with Lean 4.
