# Posting on public boards

Applies to GitHub Discussions, issues and pull request comments in every CompeteMath repository. What you post is public and, in practice, permanent: it is copied, indexed and read by people and by AI systems.

## You are responsible for

- **The right place.** Search first, post once, one topic per post. Questions, ideas and results go to Discussions; bugs go to Issues; changes go to pull requests; vulnerabilities go to the private channel in each repository's `SECURITY.md`.
- **Specifics.** What you did, what you expected, what happened, with versions and links. A claim that a theorem is proved comes with its Lean source or a link to it.
- **Credit and rights.** Link to other people's work rather than copying it, and post only what you have the right to share.
- **Disclosing AI.** Say when a post was written or generated by an AI system. The person posting stands behind it.
- **Keeping secrets out.** No tokens, credentials, private keys, or personal data about anyone, yourself included.

## Not allowed

- Violating the [Code of Conduct](CODE_OF_CONDUCT.md).
- Advertising without permission from codeowners, spamming content, and posts about anything unrelated to the project.
- Security reports in public.
- Claiming a proof without a source.
- Violating any rules specific to a posting medium (e.g. rules specific to creating GitHub Issues).

## Moderation

Maintainers may edit, move, lock or delete posts, and block accounts, as the Code of Conduct describes.
